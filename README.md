## 📲 Installation — Android (Mobile, Zalith Launcher / PojavLauncher)

1. Download the pack `.zip` file from the Releases page above. **Do NOT unzip it.**
2. Install **ZArchiver** (free) from the Play Store: https://play.google.com/store/apps/details?id=ru.zdevs.zarchiver
3. Open ZArchiver and go to: **Android → data → (your launcher's folder) → files → .minecraft**
   - For **Zalith Launcher**, open the launcher's folder inside `Android/data`, then `files`, then `.minecraft`.
   - If ZArchiver asks for permission to open `Android/data`, allow it.
   - **Can't see `.minecraft`?** It is a hidden folder. In ZArchiver, open the menu (⋮) → Settings → turn on **Show hidden files** — the folder will appear.
4. If your launcher shows version/instance folders inside `.minecraft`, open your own version's folder, then open the **resourcepacks** folder.
5. Copy / move the downloaded `.zip` into the **resourcepacks** folder (still zipped — do not extract it).
6. Open your launcher → start Minecraft → **Options → Resource Packs** → select **FSD ETC Purple Pack** → **Done**. Enjoy!

## 💻 Installation — PC (Windows / Mac / Linux)

1. Download the pack `.zip` file from the Releases page above. **Do NOT unzip it.**
2. Open **Minecraft Java Edition → Options → Resource Packs → Open Pack Folder**.
3. Move the `.zip` into the **resourcepacks** folder that opens.
4. Back in the game, select **FSD ETC Purple Pack** in the list and click **Done**.

Manual paths (if you prefer): Windows — `%appdata%\.minecraft\resourcepacks` • macOS — `~/Library/Application Support/minecraft/resourcepacks` • Linux — `~/.minecraft/resourcepacks`

## ✅ Compatibility

## ❓ Troubleshooting

- **Pack doesn't appear in the list:** make sure the file is still a `.zip` (not extracted) and that it is inside the `resourcepacks` folder.
- **`.minecraft` folder not visible on mobile:** enable **Show hidden files** in ZArchiver's settings (see step 3 above).
- **`Android/data` won't open:** allow the storage permission ZArchiver asks for; on some phones you must confirm the folder access once.
